# 🕵️ 교실 마피아

교실에서 학생들이 스마트폰·크롬북으로 함께 하는 웹 마피아 게임입니다.
선생님 PC가 서버가 되고, **Cloudflare 터널**이 학생용 인터넷 주소(`https://○○○.trycloudflare.com`)를 자동으로 만들어 줍니다.
선생님 PC가 유선이고 학생 기기가 와이파이처럼 **네트워크가 나뉘어 있어도** 접속할 수 있습니다. 회원가입이나 배포는 필요 없습니다.

---

## 0. 추천: 인터넷(Render)에 올려서 쓰기

학교 네트워크가 선생님 PC(유선)와 학생 기기(와이파이)를 나눠 두었거나 터널이 막혀 있다면, 무료 웹 호스팅 **Render**에 올려서 쓰는 방법이 가장 확실합니다.
선생님 PC에 아무것도 설치하거나 켜 둘 필요가 없고, 주소가 항상 같습니다. (예: `https://classroom-mafia-ab12.onrender.com`)

### 처음 한 번만 (15분 정도)
1. **GitHub 가입**: https://github.com 에서 무료 계정을 만듭니다.
2. **저장소 만들기**: 오른쪽 위 **[+] → New repository**
   - Repository name: `classroom-mafia`, **Public** 선택 → **[Create repository]**
3. **파일 올리기**: 만들어진 화면에서 **uploading an existing file** 링크를 누르고,
   `mafia-game-업로드용` 폴더 **안의 파일과 폴더를 모두** 끌어다 놓은 뒤 **[Commit changes]**
   (`node_modules` 폴더는 올리지 마세요. 업로드용 폴더에는 이미 빠져 있어요.)
4. **Render 가입**: https://render.com 에서 **GitHub로 로그인**합니다. 무료 요금제는 카드 등록이 필요 없어요.
5. **서버 만들기**: Render 대시보드에서 **[New +] → Blueprint** → `classroom-mafia` 저장소 선택
   - **TEACHER_PIN** 을 물어보면 선생님 비밀번호로 쓸 **숫자 4~12자리**를 입력하세요. (학생에게 알려 주지 마세요)
   - **[Deploy Blueprint]** → 3~5분 뒤 `Live` 가 되면 완료
6. 서비스 화면 위쪽의 주소(`https://….onrender.com`)가 **학생 접속 주소**입니다.

### 수업 때마다
1. 수업 **5분 전에** 선생님 PC 브라우저에서 `https://(내 주소).onrender.com/teacher` 를 열고 TEACHER_PIN을 입력합니다.
   - 무료 서버는 한동안 안 쓰면 잠들어서, **처음 열 때 1분 정도** 걸릴 수 있어요.
   - 선생님 화면을 열어 두는 동안에는 서버가 잠들지 않아요. **게임 중에는 선생님 화면을 닫지 마세요.** (잠들면 진행 중인 게임이 사라져요)
2. 화면에 나오는 주소/QR로 학생들이 접속합니다. 그다음은 아래 3~4장과 같습니다.

### 코드를 고친 뒤 다시 올리려면
GitHub 저장소에서 **Add file → Upload files** 로 바뀐 파일을 다시 올리면 Render가 몇 분 안에 자동으로 다시 배포합니다.
(TEACHER_PIN을 바꾸려면 Render 서비스 → **Environment** 에서 바꿉니다.)

---

> 아래 1~2장은 **선생님 PC에서 직접 서버를 켜는 방법**입니다. 선생님 PC와 학생 기기가 같은 와이파이일 때만 쓰세요.

## 1. 처음 한 번만: 준비하기

### ① Node.js 설치
1. https://nodejs.org 에 들어가서 **LTS** 버전을 내려받아 설치합니다. (설치 중 나오는 옵션은 기본값 그대로 두고 [Next]만 누르면 됩니다.)
2. 설치가 끝나면 PowerShell(또는 명령 프롬프트)을 **새로 열고** 아래를 입력해 버전이 나오면 성공입니다.
   ```powershell
   node -v
   ```

### ② cloudflared 설치 (학생용 인터넷 주소를 만드는 Cloudflare 공식 프로그램)
PowerShell에서 아래를 한 번 실행합니다.
```powershell
winget install --id Cloudflare.cloudflared -e
```
(또는 https://github.com/cloudflare/cloudflared/releases 에서 `cloudflared-windows-amd64.exe` 를 받아 이름을 `cloudflared.exe` 로 바꾼 뒤 `mafia-game` 폴더에 넣어도 됩니다.)

### ③ 게임에 필요한 부품 설치
`mafia-game` 폴더에서 아래 명령을 한 번 실행합니다. (인터넷이 필요하고, 1분 정도 걸려요)
```powershell
cd "$HOME\Desktop\claude\mafia-game"
npm install
```

> 💡 더 쉬운 방법: `mafia-game` 폴더의 **`시작하기.bat`** 를 더블클릭하면 ③과 서버 실행을 한 번에 해 줍니다.

## 2. 수업 때마다: 게임 시작하기

1. **서버 켜기**: `시작하기.bat` 더블클릭 (또는 폴더에서 `npm start`)
   - 검은 창에 **🔑 선생님 비밀번호**(숫자 6자리)가 나옵니다. 서버를 켤 때마다 바뀝니다.
   - **이 창은 수업이 끝날 때까지 닫지 마세요.** 닫으면 게임과 인터넷 주소가 모두 꺼집니다.
2. **선생님 화면**이 브라우저에 자동으로 열리고, 비밀번호도 자동으로 입력됩니다.
   - 10~30초 뒤 **학생용 인터넷 주소**(`○○○.trycloudflare.com`)와 QR 코드가 나타납니다. TV에 띄워 주세요.
   - TV에 띄울 때는 **[🙈 직업 가리기]** 를 눌러 직업과 밤 행동을 가리세요.
   - 선생님 화면을 다시 열어야 하면 `http://localhost:3000/teacher` 로 들어가 검은 창의 비밀번호를 입력하세요.
3. **학생 접속**: 학생들은 QR을 찍거나 인터넷 주소를 입력해서 들어가고, 방 코드와 닉네임을 입력합니다.
   - 인터넷 주소는 서버를 켤 때마다 바뀝니다. 매 수업 화면에 나온 새 주소를 알려 주세요.
4. 6~12명이 모이면 선생님 화면에서 **[▶ 게임 시작]**.
5. 끝나면 검은 서버 창에서 `Ctrl + C` 를 누르거나 창을 닫습니다.

## 3. 게임 규칙

| 직업 | 할 일 |
|---|---|
| 🔪 마피아 (1~4명, 선생님이 정함) | 밤마다 동료와 함께 한 명을 제거합니다. 서로 누가 마피아인지 알고, 밤에는 마피아 채팅을 쓸 수 있어요. |
| 💉 의사 (0~1명) | 밤마다 한 명을 지킵니다. 마피아가 그 사람을 노리면 살아남아요. 자기 자신도 지킬 수 있어요. |
| 🚓 경찰 (0~1명) | 밤마다 한 명을 조사해서 마피아인지 아닌지 알아냅니다. 결과는 아침에 자기 직업 카드에 나와요. |
| 🙂 시민 | 토론과 투표로 마피아를 찾습니다. 밤에는 "의심 가는 사람"을 고르는데, 결과에는 영향이 없고 **모두가 똑같이 화면을 눌러서 누가 특수 직업인지 티 나지 않게** 하려는 장치예요. |

**진행 순서**: 대기실 → ☀️ 낮 토론(기본 3분) → 🗳️ 투표 → ⚖️ 처형 결과 → 🌙 밤 → 🌅 아침 결과 → 다시 낮…

- 투표에서 **가장 많은 표**를 받은 한 명이 처형됩니다. **동점이거나 기권이 더 많으면** 아무도 처형되지 않아요.
- 모두 투표하면 3초 뒤, 밤에 마피아·의사·경찰이 모두 고르면 5초 뒤 자동으로 다음 단계로 넘어갑니다.
- **마피아 수 ≥ 나머지 사람 수** 가 되면 마피아 승리, **마피아가 모두 탈락**하면 시민 승리입니다.
- 탈락한 학생은
  - 👻 **유령 채팅**: 탈락한 사람끼리만 보이는 채팅
  - 🔮 **관전 예측**: 누가 마피아인지 골라 두면, 게임이 끝날 때 몇 명 맞혔는지 공개됩니다.

**추천 마피아 수**: 6~7명 → 1명 · 8~10명 → 2명 · 11~12명 → 3명

## 4. 선생님(사회자) 화면 기능

- **전체 직업 보기**: 참가자 표에서 모든 학생의 직업, 투표 현황, 밤 행동(마피아 대상·의사 보호·경찰 조사)을 실시간으로 봅니다.
- **진행 조절**: ⏭ 다음 단계로(토론 즉시 종료 등) · −30초 / +30초 · ⏸ 일시정지 · ↺ 대기실로(재시작)
- **설정**: 마피아 수, 의사·경찰 포함 여부, 단계별 시간, 죽으면 직업 공개 여부, 학생 채팅 켜고 끄기, 방별 추가 금지어
- **학생 내보내기**: 참가자 표의 [내보내기]
- **📢 사회자 공지**: 모든 학생의 전체 채팅에 공지를 띄웁니다.
- **채팅 모니터**: 전체·마피아·유령 채팅을 모두 볼 수 있어요.
- 같은 학생들로 다시 하려면 게임이 끝난 뒤 **[▶ 같은 인원으로 새 게임]**. 직업은 다시 무작위로 배정됩니다.

---

## 5. 혼자서 테스트하는 방법

1. 서버를 켜면 선생님 화면이 자동으로 열립니다.
2. 같은 브라우저에서 **새 탭을 6개** 열고 각각 `http://localhost:3000` 에 들어가 방 코드와 서로 다른 닉네임으로 입장합니다.
   (탭마다 다른 참가자로 인식돼요. 탭을 새로고침해도 같은 참가자로 다시 연결됩니다.)
3. 선생님 화면에서 게임을 시작하고, 탭을 오가며 투표·밤 행동을 해 봅니다.

> 테스트할 때 인원을 줄이고 싶으면 PowerShell에서 `$env:MIN_PLAYERS=3; npm start` 처럼 최소 인원을 바꿔 실행할 수 있어요.

## 6. 안전장치

- **직업은 서버에만 있습니다.** 학생 브라우저에는 자기 직업(마피아는 동료 마피아)만 전달되므로 개발자 도구를 열어도 다른 사람 직업을 볼 수 없습니다.
- **선생님 화면은 비밀번호로 잠겨 있습니다.** 학생이 `/teacher` 주소로 들어와도 비밀번호 없이는 아무것도 볼 수 없고, 5번 틀리면 5분 동안 잠깁니다.
  비밀번호는 서버를 켤 때마다 새로 만들어지며 검은 서버 창에만 나옵니다. 그래서 태블릿 같은 다른 기기에서도 비밀번호를 입력하면 사회자를 할 수 있습니다.
  (매번 같은 비밀번호를 쓰고 싶으면 `$env:TEACHER_PIN='246810'; npm start`)
- **인터넷 주소(터널)**: 서버가 켜져 있는 동안만 열리고, 창을 닫으면 사라지는 임시 주소입니다. 주소를 아는 사람은 학교 밖에서도 학생 입장 화면에 들어올 수 있으니 수업 중에만 켜 두세요.
  같은 와이파이에서만 쓰고 싶으면 `$env:TUNNEL='0'; npm start` 로 실행하면 터널을 만들지 않습니다.
- **비속어 필터**: 채팅과 닉네임의 욕설은 `***` 로 가려집니다. 띄어쓰기·숫자를 끼워 넣어도 걸러져요. 기본 금지어는 `filter.js` 에서, 방마다 추가 금지어는 선생님 화면 설정에서 추가할 수 있습니다.
- **개인정보 없음**: 닉네임 말고는 아무것도 받지 않으며, 서버를 끄면 모든 기록이 사라집니다. 데이터베이스나 외부 서비스를 쓰지 않습니다.
- 도배 방지(0.7초에 한 번), 메시지 길이 제한(120자)이 있습니다.

## 7. 문제 해결

| 증상 | 해결 방법 |
|---|---|
| `node` 를 찾을 수 없다고 나와요 | Node.js 설치 후 PowerShell 창을 **새로** 여세요. 그래도 안 되면 PC를 다시 시작하세요. |
| 인터넷 주소가 안 나와요 / "터널이 끊겼어요" | 서버 창을 닫고 `시작하기.bat` 을 다시 실행하세요. 계속 안 되면 학교 보안 프로그램이 Cloudflare 연결을 막는 것일 수 있어요. 정보 담당 선생님께 `trycloudflare.com` 허용을 문의하세요. |
| 학생 크롬북에서 인터넷 주소가 안 열려요 | 학생용 와이파이의 웹 필터가 `trycloudflare.com` 을 막는 경우예요. 선생님 PC 브라우저에서는 열리는지 먼저 확인하고, 정보 담당 선생님께 허용을 요청하세요. 처음 몇 초는 주소가 준비 중일 수 있으니 잠시 뒤 새로고침해 보세요. |
| 선생님 비밀번호를 잊었어요 | Render: 서비스 → **Environment** 에서 TEACHER_PIN 확인·변경. 선생님 PC에서 켠 경우: 검은 서버 창 위쪽의 🔑 줄에 있어요. |
| (Render) 주소가 한참 안 열려요 | 무료 서버가 잠들었다가 깨어나는 중이에요. 1분 정도 기다렸다 새로고침하세요. |
| (Render) 게임 도중 모두 대기실 화면/입장 화면이 됐어요 | 서버가 잠들었거나 다시 배포되어 게임이 초기화된 거예요. 게임 중에는 선생님 화면을 열어 두고, 수업 중에는 GitHub에 파일을 올리지 마세요. |
| (같은 와이파이 모드) 주소가 여러 개 나와요 | 보통 **Wi-Fi** 라고 적힌 주소가 맞아요. 하나씩 시도해 보세요. |
| 3000번 포트를 이미 쓰고 있대요 | `$env:PORT=3001; npm start` 처럼 다른 번호로 실행하세요. 학생 주소의 `:3000` 도 `:3001` 로 바뀝니다. |
| 학생이 새로고침했어요 | 같은 탭이면 자동으로 다시 연결됩니다. 탭을 닫았다면 게임 중에는 다시 들어올 수 없어요(대기실에서는 가능). |
| 선생님 화면을 실수로 닫았어요 | 같은 PC 브라우저에서 `http://localhost:3000/teacher` 를 다시 열면 원래 방으로 돌아옵니다. |

## 폴더 구성

```
mafia-game/
├─ server.js        게임 서버 (규칙, 직업 배정, 타이머)
├─ filter.js        비속어 필터
├─ 시작하기.bat      더블클릭 실행 (선생님 PC에서 서버를 켤 때)
├─ render.yaml      Render 배포 설정
├─ views/teacher.html   선생님 화면
└─ public/          학생 화면 (index.html, student.js), 공통 스타일
```
